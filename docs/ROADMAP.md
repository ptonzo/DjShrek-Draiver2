## Этап 2 — база производителей и каталогов

- [x] Единый реестр официальных источников NVIDIA, AMD, Intel, Realtek, Qualcomm, MediaTek, Broadcom, основных OEM и ряда периферийных/USB-производителей (Logitech, Chicony, SteelSeries, Razer, Corsair, FTDI, Silicon Labs, Prolific, WCH, Arduino и др.).
- [x] Определение приоритетного домена по Hardware ID (PCI/USB/HDAUDIO) с резервным определением по производителю устройства/драйвера.
- [x] Поиск по Hardware ID ограничивается доменом определённого производителя и отдельно помеченными независимыми каталогами.
- [x] NVIDIA: подключён официальный lookup к обнаруженным GPU; нечеткие названия не принимаются, выдаются только найденные официальные страницы.
- [x] Первые машинно-читаемые OEM-адаптеры Lenovo SCCM catalogv2.xml и Dell DriverPackCatalog CAB/XML: выбор пакетов по MTM/System ID, ОС, архитектуре и прямым ссылкам.
- [x] NVIDIA lookupValueSearch/processFind: получение серий (PSID), продуктов (PFID с проверкой ParentID) и ОС из официального XML API; точное сопоставление имени GPU и ссылки на страницу результатов. Пакет и INF автоматически не подтверждаются.
- [ ] Машинно-читаемый каталог AMD. Для AMD добавлен только честно маркированный переход на официальный Drivers and Support по обнаруженному VEN_1002/VEN_1022; это не каталог пакетов и не считается завершением адаптера.\n- [x] Intel DSA feed: загрузка ZIP `dsadata.intel.com/data/en`, ограничение размера, безопасный разбор `software-configurations.json`, сверка `X-DSA-Hash` (SHA-1, если заголовок предоставлен), сопоставление `Components[].DetectionValues` только при наличии конкретного Intel PCI VEN/DEV или USB VID/PID (vendor-only совпадения отклоняются), фильтрация явных метаданных Windows 10/11 и извлечение HTTPS-пакета с `downloadmirror.intel.com`. Кандидат не считается совместимым до проверки INF/CAT; SHA-1 feed header не является подписью издателя.
- [ ] Полноценный каталог пакетов Acer (сейчас доступна только SMBIOS-идентификация и ссылка на официальный портал).
- [ ] Машинно-читаемый каталог MSI: SMBIOS-идентификация платы и официальный портал поддержки реализованы; ранее предполагавшийся API endpoint не подтверждён документацией и удалён, чтобы не выдавать неподтверждённые результаты.
- [x] GIGABYTE DownloadCenter API: каталог материнских плат, карточка продукта и перечень пакетов драйверов; модель платы сопоставляется только по точному нормализованному имени, неоднозначные совпадения отклоняются.
- [ ] ASUS ProductV2/GetPDDrivers и Product.asmx/GetPDLevel: низкоуровневый API-клиент принимает только реальные PDId/PDHashedId; автоматическое разрешение этих идентификаторов из SMBIOS-модели не реализовано. До этого приложение показывает только официальный портал поддержки и не формирует фиктивные результаты.
- [x] Получение модельных пакетов Dell по SMBIOS System ID, Lenovo по Machine Type (MTM) и HP по SMBIOS SystemSKU.
- [x] Автоматическое получение метаданных OEM-модели HP из HP Client Driver Pack Catalog.
- [ ] Автоматическое получение списка драйверов ASUS: требуется изучить и связать реальные уровни Product.asmx/GetPDLevel с точным ProductId/PDHashedId перед запросом ProductV2.
- [x] Получение SMBIOS-идентификаторов Acer и переход к официальной странице Drivers and Manuals без автоматической отправки серийного номера.
- [ ] Автоматическое получение машинно-читаемых метаданных и пакетов Acer.
- [ ] Подписанный ECDSA-манифест каталога: удалённая загрузка отключена до создания и безопасного хранения реального закрытого ключа издателя, закрепления соответствующего открытого ключа в приложении и публикации подписанного payload.
- [ ] Обновление базы источников с криптографической проверкой: приложение сейчас использует встроенный реестр; неподтверждённый удалённый манифест не загружается и не принимается.

Реестр источников — это маршрутизация поиска, а не база готовых драйверов. Сейчас модельные пакеты извлекаются из каталогов Lenovo, Dell и HP; Intel DSA предоставляет компонентные записи и ссылки на пакеты для совпавших DetectionValues. Обновление реестра из сети временно отключено до настройки реального ключевого материала; приложение использует встроенную базу. Эти записи не являются подтверждёнными обновлениями отдельных устройств: версии драйверов извлекаются из INF после загрузки, а пакет проходит общий preflight INF/CAT. Для Dell и HP CAB проверяются через Windows Get-AuthenticodeSignature: требуется статус Valid и сертификат соответствующего издателя. Это проверка подписи и цепочки средствами Windows; после извлечения пакет всё равно проходит отдельную проверку INF/CAT.

## Важное ограничение текущей версии

Текущий поиск находит официальные страницы поддержки, но не является полноценным каталогом готовых драйверных пакетов. Он не подтверждает автоматически версию и совместимость пакета, не скачивает драйвер и не выполняет автоматическую установку. Эти возможности нельзя считать реализованными до прохождения перечисленных проверок.
