# Roadmap

## Milestone 0 — Repository foundation
- [x] Создать отдельный репозиторий.
- [x] Зафиксировать назначение, границы и архитектурные принципы.
- [ ] Добавить .NET solution и проекты.
- [ ] Добавить форматирование, анализаторы и тестовый pipeline.

## Milestone 1 — Application shell
- [ ] WPF shell с навигацией и фирменной темой DjShrek-Draiver.
- [ ] Dashboard с реальными состояниями, без фиктивных показателей.
- [ ] Локальные настройки и журнал операций.

## Milestone 2 — Device inventory
- [x] Инвентаризация PnP-устройств через Windows CIM/PnP.
- [x] Hardware ID, Compatible ID, статус, производитель и текущий INF/драйвер.
- [ ] Тесты на обработку отсутствующих/неисправных устройств.

## Milestone 3 — Driver metadata and verification
- [x] Адаптеры каталогов производителей и поиск страниц по Hardware ID.
- [x] Чтение INF: поставщик, класс, DriverVer, дата, CatalogFile и идентификаторы моделей.
- [x] Локальное сопоставление INF с устройствами, архитектурой и диапазоном сборок Windows.
- [ ] Проверка цифровой подписи и хэша для каждого загружаемого пакета из каталога.
- [ ] UI сравнения версий и источников.

## Milestone 4 — Backup and controlled install
- [ ] Экспорт драйверов штатными средствами Windows.
- [ ] Верификация резервной копии.
- [ ] Установка с повышением прав и явным подтверждением.
- [ ] Отчёт, отмена и рекомендации восстановления.

## Milestone 5 — Monitoring and diagnostics
- [ ] CPU/RAM/disk baseline.
- [ ] GPU и температуры через доступные провайдеры.
- [ ] Диагностические проверки сети и звука.

## Milestone 6 — Release engineering
- [ ] Подпись приложения и установщика.
- [ ] CI для сборки и тестов Windows.
- [ ] Проверка чистой установки и обновления на Windows 10/11.
- [ ] Публикация релиза с контрольными суммами и примечаниями.
