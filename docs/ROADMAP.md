# Дорожная карта DjShrek-Draiver Cyber Club

Статусы ниже отражают код в ветке `feature/in-app-driver-update-center`, а не планы или макеты. Успешная CI-сборка не заменяет проверку на физических ПК с Windows 10/11.

## Реализовано

- [x] WPF-приложение .NET 8 с шестью экранами: главная, устройства, драйверы, реестр, очистка, настройки.
- [x] 12 тем оформления, сохранение выбранной темы и языка.
- [x] Панель мониторинга CPU/RAM/диска и доступных аппаратных датчиков.
- [x] Инвентаризация PnP-устройств, Hardware ID и сведений об установленных драйверах.
- [x] Сопоставление устройств по точным Hardware ID; неоднозначные общие Compatible ID не назначаются произвольно.
- [x] Поиск страниц производителей по Hardware ID через веб-поиск и фильтрация ссылок по HTTPS и списку официальных доменов.
- [x] Разделение найденной страницы и подтверждённой совместимости пакета: найденная ссылка не считается готовым обновлением.
- [x] Резервное копирование и восстановление Driver Store штатными средствами Windows.
- [x] Предварительная проверка INF-пакета на наличие каталога и цифровой подписи.
- [x] Диагностика записей автозапуска с резервной копией перед исправлением.
- [x] Консервативная очистка старых временных файлов.
- [x] Windows CI: сборка, WPF smoke test, публикация переносимого пакета и установщика.
- [x] Регрессионные проверки сопоставления Hardware ID и проверки официальных URL.

## Этап 2 — база производителей и каталогов

- [x] Единый реестр официальных источников NVIDIA, AMD, Intel, Realtek, Qualcomm, MediaTek, Broadcom и основных OEM.
- [x] Определение приоритетного домена по Hardware ID (PCI/USB/HDAUDIO) с резервным определением по производителю устройства/драйвера.
- [x] Поиск по Hardware ID ограничивается доменом определённого производителя и отдельно помеченными независимыми каталогами.
- [ ] Машинно-читаемые адаптеры каталогов производителей с выдачей версии, даты, ОС, архитектуры и прямого URL пакета.
- [ ] Автоматическое получение метаданных OEM-модели (Dell/HP/Lenovo/ASUS/Acer/MSI/GIGABYTE).
- [ ] Подписанный манифест каталога с закреплённым открытым ключом в клиенте.
- [ ] Автоматическое обновление базы источников с проверкой подписи и срока актуальности.

Реестр источников — это маршрутизация поиска, а не база готовых драйверов. Пока адаптер не извлёк метаданные конкретного пакета и пакет не прошёл проверки, результат остаётся ссылкой на источник и не может быть установлен.

## Важное ограничение текущей версии

Текущий поиск находит официальные страницы поддержки, но не является полноценным каталогом готовых драйверных пакетов. Он не подтверждает автоматически версию и совместимость пакета, не скачивает драйвер и не выполняет автоматическую установку. Эти возможности нельзя считать реализованными до прохождения перечисленных проверок.
