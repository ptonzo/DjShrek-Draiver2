# Бесплатный локальный AI-разработчик для DjShrek-Draiver

## Как это работает
Локальная модель Ollama генерирует код на компьютере пользователя. Aider применяет изменения в Git-репозитории. PowerShell-скрипт запускает ограниченное число циклов, собирает WPF-приложение и отправляет успешные изменения в отдельную ветку `ai/local-development`. Платные API-ключи не используются.

Это не бесконечный облачный процесс: ПК должен быть включён, пользователь вошёл в Windows, Ollama запущен, а интернет нужен для GitHub и первоначальной загрузки модели. Само общение с моделью идёт через локальный Ollama.

## Установка на Windows 10/11

1. Установить Ollama: https://ollama.com/download/windows
2. Открыть PowerShell и выполнить:

```powershell
ollama pull qwen2.5-coder:7b
py -m pip install --user aider-chat
```

Если команда `py` отсутствует, установить Python 3.11+ с python.org и включить Python Launcher.
3. Проверить:

```powershell
ollama list
aider --version
```

4. Клонировать репозиторий и перейти в него:

```powershell
git clone https://github.com/ptonzo/DjShrek-Draiver2.git
cd DjShrek-Draiver2
```

5. Установить .NET 8 SDK (Windows x64): https://dotnet.microsoft.com/download/dotnet/8.0
6. Запустить разработчика:

```powershell
.\scripts\Start-LocalAIDeveloper.ps1 -Iterations 2
```

Скрипт создаёт/использует отдельную ветку `ai/local-development`, не меняет `main`, не разрешает модели выполнять произвольные shell-команды, после каждого цикла выполняет Release build и self-test. Только если сборка и self-test проходят, изменения коммитятся и отправляются в отдельную ветку. Для отправки потребуется авторизованный GitHub CLI или Git Credential Manager.

## Ресурсы
Для видеокарты RTX 3060 Ti 8 GB начни с Qwen2.5-Coder 7B. Это компромисс по качеству и памяти, а не уровень облачных моделей. Если модель работает медленно или выгружается в RAM, уменьши параллельные задачи и закрой тяжёлые приложения. Ollama может работать и на CPU, но заметно медленнее.

## Ограничения и безопасность
- Бесплатно в смысле отсутствия платного AI API; электричество, интернет и ресурсы ПК остаются необходимыми.
- Агент не должен автоматически устанавливать драйверы на Windows. Он разрабатывает и собирает приложение; реальные установки и аппаратные проверки остаются под контролем пользователя.
- Сборка проходит локально. Публикация ветки требует GitHub-аутентификации.
- Не запускать скрипт от имени администратора.
- Просмотреть изменения в ветке перед слиянием в main.
