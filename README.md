# DjShrek-Draiver Cyber Club

Самостоятельная WPF-утилита для Windows 10/11 x64 на C#/.NET 8. Проект развивает интерфейс управления ПК, инвентаризацию устройств, мониторинг и безопасные операции обслуживания. Это не копия закрытого кода или базы Driver Booster.

## Разделы приложения

1. **Главная панель** — сведения о CPU, GPU, RAM, системном диске, Windows, модели компьютера и времени работы; датчики показываются только если источник реально доступен.
2. **Устройства** — PnP-инвентаризация с именем устройства, классом, производителем, состоянием, кодом проблемы, Hardware ID и Compatible ID, версией/датой/поставщиком драйвера и сведениями о подписи.
3. **Драйверы** — поиск страниц производителей по Hardware ID, просмотр установленных пакетов Driver Store, экспорт/восстановление резервной копии и ручная установка выбранного INF.
4. **Реестр** — диагностика стандартных разделов Run/RunOnce. Исправление ограничено подтверждёнными проблемными записями HKCU с предварительным экспортом .reg; HKLM доступен только для чтения.
5. **Очистка** — поиск временных файлов старше семи дней в ограниченных временных каталогах. Перед удалением пользователь выбирает элементы и подтверждает операцию.
6. **Настройки** — двенадцать тем оформления и языковые настройки.

## Поиск драйверов: текущая реализация и ограничения

Приложение самостоятельно отправляет поисковые HTTPS-запросы по Hardware ID через публичный RSS-интерфейс Bing. Результаты фильтруются по доменам известных производителей (Intel, NVIDIA, AMD, Dell, HP, Lenovo, ASUS, Acer, MSI, Realtek, Qualcomm, MediaTek, Broadcom и др.). Это поиск официальных страниц поддержки, а не полноценный индекс бинарных пакетов драйверов.

Совпадение Hardware ID в поисковом запросе **не доказывает совместимость конкретного пакета**. Программа показывает это ограничение в интерфейсе, сопоставляет результат с устройством по полному Hardware ID/Compatible ID и разрешает открытие только HTTPS-ссылок на домены из встроенного списка производителей. Поддомены допускаются; домены-двойники, HTTP и произвольные URL отклоняются.

**Важные ограничения:** поиск пока не извлекает из страницы производителя готовый пакет, не устанавливает его автоматически и не подтверждает доступную версию драйвера. Пользователь должен проверить модель ПК/устройства, версию Windows, архитектуру и подпись скачанного пакета. Нельзя считать найденную страницу подтверждением того, что драйвер новее установленного.

Ручная установка INF — отдельная операция. Приложение проверяет, что INF существует, что он ссылается на CAT-файл и что подпись найденного CAT имеет статус Valid; затем запрашивает UAC и передаёт пакет штатной утилите Windows. Успешный код возврата команды не гарантирует, что устройство фактически переключилось на новую версию: после установки требуется повторная проверка в диспетчере устройств. Не устанавливайте пакет, если не уверены в его происхождении и совместимости.

## Безопасность обслуживания

- Системные изменения требуют отдельного действия пользователя.
- Экспорт драйверов выполняется штатным pnputil; резервная папка должна быть пустой, после экспорта проверяется наличие INF.
- Перед восстановлением проверяются подписи CAT всех INF-пакетов; неподтверждённый пакет блокирует операцию.
- Реестр сканируется без изменений; автоматическое удаление ограничено проверяемыми записями HKCU и сопровождается резервной копией.
- Очистка ограничена временными каталогами; личные папки, загрузки, документы, фотографии и браузерные данные не должны затрагиваться.
- Датчики, которые не удалось прочитать, отображаются как недоступные, а не заменяются вымышленными значениями.

## Сборка и самопроверка

Требуются Windows 10/11 x64 и .NET 8 SDK.

```powershell
.\\scripts\\Generate-Icon.ps1
dotnet restore .\\src\\DjShrek.Draiver.App\\DjShrek.Draiver.App.csproj
dotnet build .\\src\\DjShrek.Draiver.App\\DjShrek.Draiver.App.csproj -c Release
dotnet run --project .\\src\\DjShrek.Draiver.App\\DjShrek.Draiver.App.csproj -c Release -- --self-test
```

Windows CI компилирует приложение, проверяет XAML, запускает WPF smoke-test на Windows runner и собирает self-contained x64 публикацию и Inno Setup installer. Самопроверка включает наличие шести экранов, двенадцати тем, PnP-инвентаризацию, системную телеметрию, точное сопоставление Hardware ID, проверку доменов официальных ссылок, безопасные тестовые сценарии реестра/очистки и отказ от INF без подписанного CAT.

Успешная CI-сборка подтверждает компиляцию и прохождение автоматических проверок на виртуальной Windows-машине. Она **не заменяет испытание на реальном ПК** с конкретным оборудованием и не доказывает совместимость драйверов для всех моделей Windows 10/11.
