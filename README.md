# DjShrek-Draiver Cyber Club

Самостоятельная Windows-утилита для инвентаризации оборудования и безопасного обслуживания драйверов. Проект не копирует закрытый код, графику или базу Driver Booster.

## Функции версии 1.2.0
- Тёмная WPF-панель управления.
- Мониторинг загрузки CPU и использования RAM с автообновлением каждые 5 секунд.
- Сведения об установленной Windows.
- Инвентаризация PnP-устройств: имя, класс, состояние, Instance ID и код конфигурационной ошибки.
- Поиск по устройствам и фильтр проблемных устройств.
- Экспорт полной инвентаризации в CSV (UTF-8 с BOM).
- Проверка Driver Store и просмотр установленных пакетов через `pnputil /enum-drivers`.
- Резервное копирование установленных пакетов через `pnputil /export-driver`.
- Установка выбранного INF через `pnputil /add-driver /install`, с отдельным подтверждением и UAC.
- Восстановление пакетов из папки резервной копии с рекурсивным поиском INF и подтверждением.
- Встроенный поиск доступных драйверов через Microsoft Windows Update Agent (WUA).
- Просмотр названия пакета, производителя, модели, версии и даты до установки.
- Установка только тех Update ID, которые были показаны в проверенном списке; перед установкой требуется подтверждение и UAC.
- Переход к официальным необязательным обновлениям Windows как дополнительный системный путь.
- Сборка self-contained Windows x64 EXE через GitHub Actions.

## Важные границы функциональности
Приложение не заявляет о наличии собственного облачного каталога драйверов, автоматического сопоставления всех устройств с новейшими версиями на сайтах производителей, обновления BIOS/прошивок, мониторинга температур GPU/CPU или игрового ускорителя. В этой версии встроенный поиск и установка используют Microsoft Windows Update Agent; доступный набор зависит от Windows Update, производителя, модели устройства и региона. Ручная установка INF и восстановление из резервной папки остаются отдельными подтверждаемыми операциями. Это исключает выдачу случайных или неподходящих драйверов за рекомендованные.

## Требования
- Windows 10/11 x64.
- Для опубликованного self-contained EXE установка .NET Runtime не требуется.
- Для разработки нужен .NET 8 SDK на Windows.

## Сборка
```powershell
dotnet restore .\DjShrek-Draiver.sln
dotnet build .\DjShrek-Draiver.sln -c Release
dotnet publish .\src\DjShrek.Draiver.App\DjShrek.Draiver.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\artifacts\win-x64
```

## Безопасность
- Инвентаризация и мониторинг не меняют конфигурацию системы.
- Резервное копирование и установка используют штатный `pnputil`.
- Операции, требующие повышения прав, вызывают UAC.
- Устанавливайте только драйверы от производителя устройства или через Windows Update.
- Экспорт драйверов не заменяет полноценный образ/резервную копию Windows.
