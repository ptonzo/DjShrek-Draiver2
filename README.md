# DjShrek-Draiver Cyber Club 1.8.0

Самостоятельная WPF-программа для Windows 10/11 x64: центр управления компьютером, контроль устройств и обслуживание драйверов. Код написан на C#/.NET 8. Проект не копирует закрытый код или базу Driver Booster.

## Интерфейс и оформление

Программа восстановлена по структуре предыдущего проекта и имеет шесть рабочих экранов:

1. **Главная** — мониторинг CPU, GPU, RAM и системного диска, сведения об оборудовании и Windows, доступные температуры, время работы и журнал действий.
2. **Драйверы и устройства** — PnP-инвентаризация, Hardware/Instance ID, поставщик, версия и дата установленного драйвера, подпись, состояние и код ошибки; поиск, фильтр проблемных устройств, CSV, резервное копирование и восстановление.
3. **Обновления драйверов** — запуск SDIO по запросу, проверка Hardware ID и переход к официальным каталогам производителей.
4. **Проверка реестра** — чтение стандартных Run/RunOnce разделов HKCU/HKLM, отчёт о подозрительных/невалидных путях; безопасная очистка ограничена подтверждёнными проблемными значениями HKCU, перед удалением создаётся экспорт .reg.
5. **Очистка компьютера** — проверяются только временные папки текущего пользователя и Windows; предлагаются файлы старше 7 дней. Есть выбор файлов и подтверждение удаления.
6. **Настройки** — двенадцать визуальных тем и выбор языка интерфейса.

Доступны все 12 тем: Neon Gaming, Glass Windows 11, Minimal Pro, Техно/Инженерный, Тёмный профессиональный, RGB Gaming, Классический, Светлый/Чистый, Киберпанк, HUD, Ангар и Полевой штаб. Тема выбирается по названию, применяется ко всем панелям и сохраняется между запусками. Для каждой темы предусмотрена отдельная палитра и векторная иллюстрация на главном экране.

## OEM-идентификация и поиск драйверов (версия 1.8.0)

- Определение производителя и модели по Win32_ComputerSystem, Win32_ComputerSystemProduct, Win32_BaseBoard и Win32_BIOS.
- Для OEM-систем дополнительно читаются BIOS-метаданные из стандартных ветвей реестра Windows; ProductNumber/System SKU используются как поисковые ключи, когда они предоставлены прошивкой.
- Адаптеры каталогов охватывают Acer, MSI, ASUS, Dell, HP, Lenovo, Gigabyte, ASRock, NVIDIA, Intel, AMD, Realtek, Qualcomm, MediaTek и Broadcom.
- Интернет-поиск формирует запросы по точным PnP Hardware ID/Compatible ID и ограничивает результаты официальными доменами производителей.
- Результат поиска — ссылка на страницу поддержки, а не готовый пакет. Версия, ОС, архитектура, цифровая подпись и соответствие INF должны быть подтверждены до установки.
- Поиск не загружает и не устанавливает найденные драйверы. Для получения индексов и ручного сопоставления сохраняется отдельный безопасный сценарий SDIO с отключённой установкой.

## Мониторинг и датчики

CPU, RAM, системный диск, название CPU/GPU, версия Windows и uptime читаются из Windows. Температуры CPU/GPU и загрузка GPU выводятся только при доступности датчиков LibreHardwareMonitor. Неподдерживаемые показания отображаются как «Нет данных» или «Н/Д» — программа не генерирует фиктивные значения. Мониторинг обновляется с интервалом 5 секунд.

## Драйверы и безопасность

В приложении нет собственной базы драйверных пакетов. После сканирования Plug and Play, по явному действию пользователя, скачивается официальный Snappy Driver Installer Origin (SDIO). Архив сверяется с закреплённой SHA-256 суммой до распаковки. Затем приложение запускает документированный сценарий SDIO: получает метаданные обновлений, загружает **только индексы** (не пакеты драйверов), отключает установку через `enableinstall off`, и формирует отчёт об оборудовании. После этого открывается интерфейс SDIO с результатами сопоставления Hardware ID. Пользователь проверяет каждый вариант и подтверждает установку вручную.

DjShrek-Draiver **не использует Windows Update Agent, WUAPI или Microsoft Update Catalog**. Автоматическая установка всех найденных кандидатов намеренно не включена: несовместимый пакет может нарушить работу видеокарты, сети, чипсета или устройств хранения. Для системных операций используются штатные средства Windows и отдельное подтверждение UAC.

Резервная копия экспортирует сторонние пакеты Driver Store через pnputil в выбранную пустую папку. Восстановление проверяет наличие INF и требует явного согласия. Ручная установка INF тоже требует отдельного подтверждения.

## Реестр и очистка

Реестр сканируется без внесения изменений. Проверяются только четыре стандартных ключа автозапуска Run/RunOnce (HKCU и HKLM). Автоматическое удаление возможно только для подтверждённой отсутствующей программы в HKCU; перед этим создаётся .reg резервная копия и проверяется, что значение не изменилось после сканирования. HKLM доступен только для отчёта.

Очистка охватывает только временную папку текущего пользователя и Windows Temp. Не сканируются и не удаляются Downloads, документы, фотографии, корзина, браузерные профили, cookies, пароли и личные данные. Символические ссылки, reparse points, занятые/изменившиеся/недоступные файлы пропускаются.

## Сборка и проверка

Требуются Windows 10/11 x64 и .NET 8 SDK.

```powershell
.\scripts\Generate-Icon.ps1
dotnet restore .\src\DjShrek.Draiver.App\DjShrek.Draiver.App.csproj
dotnet build .\src\DjShrek.Draiver.App\DjShrek.Draiver.App.csproj -c Release
dotnet run --project .\src\DjShrek.Draiver.App\DjShrek.Draiver.App.csproj -c Release -- --self-test
```

Windows CI проверяет XAML и привязку обработчиков, наличие шести экранов и двенадцати уникальных тем, собирает Release, запускает WPF smoke-test (создание окна, наличие экранов и ComboBox, выбор всех тем и применение палитр), публикует self-contained x64 EXE и компилирует Inno Setup установщик.

**Ограничение тестирования:** CI проверяет сборку и визуальную структуру на Windows runner. Реальные драйверы, доступность аппаратных датчиков и фактическую очистку/изменение реестра требуется отдельно проверять на конкретном ПК Windows 10/11. Автоматическая установка драйверов полностью без участия пользователя не реализована.

## Установка и лицензия

Запустите `DjShrek-Draiver-Cyber-Club-Setup-x64.exe`, прочитайте лицензионное соглашение и примите его. Без согласия продолжить установку нельзя. Установщик создаёт ярлык в меню «Пуск» и предлагает ярлык рабочего стола. EXE опубликован как self-contained, .NET Runtime отдельно не требуется.

Правообладатель проекта обозначен как DjShrek-Draiver. Сторонние библиотеки и SDIO сохраняют собственные лицензии и условия.
