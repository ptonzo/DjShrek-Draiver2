# DjShrek-Draiver

Самостоятельная Windows-утилита для диагностики оборудования, управления драйверами и мониторинга ПК под брендом **DjShrek-Draiver**.

> Проект создаётся с нуля. Он не содержит исходный код, закрытые ресурсы или базу драйверов Driver Booster. Совместимые функции реализуются независимо с использованием документированных интерфейсов Windows и легальных источников драйверов.

## Цели
- Windows 10/11 x64.
- Собственный интерфейс DjShrek-Draiver Cyber Club.
- Модульная архитектура для добавления функций без переписывания ядра.
- Надёжное обнаружение устройств и сопоставление по Hardware ID.
- Проверка происхождения, совместимости и цифровых подписей драйверов.
- Предварительный просмотр изменений и возможность восстановления.

## План модулей
| Модуль | Назначение |
|---|---|
| Dashboard | Состояние ПК и краткая сводка |
| Driver Scanner | Инвентаризация PnP-устройств и поиск проблем |
| Driver Catalog | Каталог метаданных и источников драйверов |
| Installer | Управляемая установка с подтверждением пользователя |
| Backup & Restore | Экспорт, резервная копия и восстановление |
| Hardware Monitor | CPU, GPU, RAM, диски и доступные датчики |
| Game Center | Игровые профили и безопасные настройки |
| Diagnostics | Диагностика сети, звука и устройств |
| Plugin System | Расширения через документированные контракты |
| License Center | Лицензирование продукта |

## Технологии
- C# / .NET 8 (Windows)
- WPF на первом этапе; UI-слой изолирован для возможной смены технологии
- SQLite для локальных настроек и кэша метаданных
- Windows SetupAPI / Configuration Manager / PnPUtil для работы с устройствами
- GitHub Actions для сборки и тестов

## Безопасность
- Не устанавливать драйверы из неизвестных источников.
- Проверять подпись пакета и издателя до установки.
- Не отключать Secure Boot, проверку подписи драйверов или защитные механизмы Windows.
- Не подменять драйверы и не выполнять установку без явного согласия пользователя.
- Перед изменением драйвера по возможности создавать резервную копию и точку восстановления.
- Не обещать наличие обновлений, если источник и совместимость не подтверждены.
