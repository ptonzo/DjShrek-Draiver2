# DjShrek-Draiver Cyber Club

Самостоятельная WPF-утилита для Windows 10/11 x64 на C#/.NET 8. Проект развивает интерфейс управления ПК, инвентаризацию устройств, мониторинг и обслуживание драйверов. Это независимая реализация, а не копия закрытого кода или базы Driver Booster.

## Разделы приложения

1. **Главная панель** — сведения о CPU, GPU, RAM, системном диске, Windows, модели компьютера и времени работы; датчики показываются только если источник реально доступен.
2. **Устройства** — PnP-инвентаризация с именем устройства, классом, производителем, состоянием, кодом проблемы, Hardware ID и Compatible ID, версией/датой/поставщиком драйвера и сведениями о подписи.
3. **Драйверы** — поиск по Hardware ID в OEM-каталогах и независимых базах, сравнение версий, загрузка пакета, анализ INF/CAT, подтверждаемая установка, история и открытие мастера отката Windows.
4. **Резервное копирование** — экспорт пакетов Driver Store, SHA-256-манифест и восстановление пакетов после проверки целостности и подписей.
5. **Инструменты исправления** — быстрый переход к штатным настройкам звука, сети, экрана, диспетчеру устройств и устранению неполадок Windows. Настройки не меняются автоматически.
6. **Игровой профиль** — включает Windows Game Mode и схему высокой производительности с возможностью вернуть сохранённые настройки.
7. **Реестр** — диагностика стандартных разделов Run/RunOnce. Исправление ограничено подтверждёнными проблемными записями HKCU с предварительным экспортом .reg; HKLM доступен только для чтения.
8. **Очистка** — поиск временных файлов старше семи дней в ограниченных временных каталогах. Перед удалением пользователь выбирает элементы и подтверждает операцию.
9. **Настройки** — двенадцать тем оформления и языковые настройки.

## Многоисточниковый поиск драйверов

Поиск выполняется по Hardware ID и объединяет несколько типов источников:

- **Сайты производителей:** Intel, NVIDIA, AMD, Dell, HP, Lenovo, ASUS, Acer, MSI, Realtek, Qualcomm, MediaTek, Broadcom и другие.
- **Независимые каталоги:** прямой поиск Driver.ru по адресу `/Search/{Hardware ID}`, а также результаты DriverGuide, FlyDrivers, DriverPack, Station-Drivers, DriversCollection и Driverscape через поисковый индекс.
- **Файловые и облачные хранилища:** загрузочные ссылки, найденные на страницах источников, включая Google Drive, Dropbox, OneDrive, Яндекс Диск, Облако Mail.ru, MEGA, MediaFire и Pixeldrain.

Результаты сводятся в единый список. При ранжировании учитываются тип источника, точность идентификатора и дата результата. Если версия не указана, программа не выдумывает её и не объявляет обновление доступным. Для записей Driver.ru извлекаются версия, дата выпуска, устройство и поддерживаемые версии Windows; версия сравнивается с установленной.

**Источник и пакет оцениваются отдельно.** Сайт из каталога не получает автоматического доверия. Для загруженного пакета выполняются проверка типа файла, ограничение размера, проверка HTTPS-перенаправлений и SHA-256. Для ZIP/CAB можно выполнить безопасную распаковку и анализ INF. Программа проверяет точный Hardware ID, архитектуру Windows, версию INF и подпись CAT. Совпадение только по Compatible ID не разрешает автоматическую установку.

## Подтверждаемое обновление

Для ZIP/CAB последовательность выглядит так:

1. Выбрать результат поиска и загрузить пакет из его источника или связанного облачного хранилища.
2. Согласиться на распаковку и анализ INF.
3. Программа ищет INF с точным Hardware ID, подходящей архитектурой, действительной подписью CAT и версией новее установленной.
4. Кнопка установки становится доступна только для прошедшего эти проверки INF.
5. Перед установкой повторно проверяются INF, версия, Hardware ID и CAT. Пользователь подтверждает действие.
6. Если текущий драйвер опубликован как OEM-пакет `oemNN.inf`, приложение экспортирует его в отдельную папку и создаёт SHA-256-манифест. Затем Windows создаёт точку восстановления и штатная утилита `pnputil` получает новый INF.
7. В истории записывается факт передачи пакета Windows. Это не считается доказательством того, что устройство уже использует новую версию: после операции требуется повторное сканирование и проверка диспетчера устройств.

EXE/MSI-пакеты не запускаются автоматически. Для них пользователь должен самостоятельно проверить подпись и использовать предусмотренный производителем сценарий установки. Автоматическая распаковка в текущей версии поддерживается для ZIP и CAB; другие архивные форматы можно сохранить, но они не проходят автоматический INF-анализ.

Кнопка отката открывает мастер восстановления системы Windows. Выберите точку `DjShrek Driver Update`, созданную перед установкой. Восстановление системы может отменить и другие изменения Windows, сделанные после выбранной точки.

## Безопасность обслуживания

- Системные изменения требуют отдельного действия пользователя и запроса UAC.
- Установка INF разрешена только после проверки точного Hardware ID, архитектуры и действительной подписи CAT; неизвестная или неподписанная подпись блокирует установку.
- Перед обновлением экспортируется текущий OEM-пакет, если Windows сообщает опубликованное имя вида `oem42.inf`; в остальных случаях используется точка восстановления Windows.
- Резервные копии сопровождаются SHA-256-манифестом. Перед восстановлением проверяются целостность файлов и подписи CAT всех INF-пакетов.
- Загрузка разрешена только по HTTPS; перенаправления на HTTP и локальные/непубличные адреса блокируются. Внешний хост загрузки не считается доверенным только потому, что он облачный.
- Реестр сканируется без изменений; автоматическое удаление ограничено проверяемыми записями HKCU и сопровождается резервной копией.
- Очистка ограничена временными каталогами; личные папки, загрузки, документы, фотографии и браузерные данные не должны затрагиваться.
- Датчики, которые не удалось прочитать, отображаются как недоступные, а не заменяются вымышленными значениями.

## Сборка и самопроверка

Требуются Windows 10/11 x64 и .NET 8 SDK.

```powershell
.\scripts\Generate-Icon.ps1
dotnet restore .\src\DjShrek.Draiver.App\DjShrek.Draiver.App.csproj
dotnet build .\src\DjShrek.Draiver.App\DjShrek.Draiver.App.csproj -c Release
dotnet run --project .\src\DjShrek.Draiver.App\DjShrek.Draiver.App.csproj -c Release -- --self-test
```

Windows CI компилирует приложение, проверяет XAML, запускает WPF smoke-test на Windows runner и собирает self-contained x64 EXE и Inno Setup installer. Самопроверка включает шесть экранов, двенадцать тем, PnP-инвентаризацию, системную телеметрию, точное сопоставление Hardware ID, домены OEM и независимых каталогов, разбор страницы Driver.ru, сравнение версий, проверку CAT-подписи и безопасные тестовые сценарии обслуживания.

Успешная CI-сборка подтверждает компиляцию и прохождение автоматических проверок на виртуальной Windows-машине. Она **не заменяет испытание на реальном ПК** с конкретным оборудованием и не доказывает совместимость драйверов для всех моделей Windows 10/11.
