# DjShrek-Draiver Cyber Club

Самостоятельная Windows-утилита для инвентаризации оборудования и обслуживания драйверов. Проект не копирует закрытый код, графику или базу Driver Booster.

## Возможности версии 1.4.0

- Тёмная WPF-панель управления с фирменной иконкой.
- Автоматическое обновление показателей CPU/RAM каждые 5 секунд.
- Температуры CPU/GPU по аппаратным датчикам через LibreHardwareMonitor.
- Официальные каталоги Dell, HP, Lenovo, ASUS, Acer, MSI, Intel, AMD, NVIDIA и Microsoft Surface.
- Обратимый игровой профиль Windows: Game Mode и схема высокой производительности с сохранением прежних настроек.
- Инвентаризация PnP-устройств: имя, производитель, класс, статус, Instance ID и код конфигурационной ошибки.
- Сведения об установленном драйвере: поставщик, версия, дата, INF-файл и подпись, если Windows предоставляет эти данные.
- Поиск устройств и установленных драйверов, фильтр проблемных устройств и экспорт подробного отчёта CSV.
- Собственный каталог драйверов DjShrek-Draiver: поиск по Hardware ID/Compatible ID, HTTPS-загрузка ZIP-пакетов, проверка SHA-256, подписи издателя и соответствия INF аппаратным ID.
- Отображение названия пакета, производителя, модели, поставщика, класса и даты драйвера.
- Ручной и автоматический сценарии поиска в независимом каталоге DjShrek-Draiver; системная установка совместимых INF-пакетов выполняется через pnputil с запросом UAC.
- Просмотр установленных сторонних пакетов Driver Store через \`pnputil /enum-drivers\`.
- Экспорт установленных пакетов через \`pnputil /export-driver\`.
- Восстановление из экспортированной папки и ручная установка доверенного INF-файла с отдельным подтверждением.
- Переход к системной странице необязательных обновлений Windows.
- Установщик Inno Setup x64 с обязательной страницей принятия лицензии, ярлыком меню «Пуск», опциональным ярлыком рабочего стола и штатным удалением.
- Самодостаточный Windows x64 EXE: устанавливать .NET Runtime отдельно не требуется.

## Независимый каталог драйверов

Поиск и загрузка выполняются собственным модулем DjShrek-Draiver. Приложение не обращается к Windows Update Agent, WUAPI или Microsoft Update Catalog. Сопоставление выполняется по Hardware ID и Compatible ID. Пакет должен иметь прямую HTTPS-ссылку на ZIP, SHA-256, поддерживаемую архитектуру/сборку Windows, аппаратные ID и ожидаемого издателя подписи.

Перед установкой программа сверяет SHA-256 архива, проверяет Hardware ID в INF и подписи CAT/SYS с ожидаемым издателем. Установка выполняется через pnputil после подтверждения пользователя и UAC. Это системный механизм установки драйверов, а не Windows Update.

**Важно:** загрузчик и формат независимого каталога реализованы, но начальный каталог пока пуст. Поэтому программа честно сообщает об отсутствии совпадений, пока в каталог не добавлены проверенные записи официальных пакетов. Универсальная база драйверов не возникает автоматически: её нужно наполнять реальными пакетами с подтверждёнными хэшами и издателями.

## Установка

1. Запустите \`DjShrek-Draiver-Cyber-Club-Setup-x64.exe\`.
2. Прочитайте лицензионное соглашение и выберите «Я принимаю условия соглашения». Без согласия продолжить интерактивную установку нельзя.
3. Выберите папку установки и при необходимости ярлык на рабочем столе.
4. После установки запустите программу через меню «Пуск» или ярлык.

Для системных операций Windows может показать запрос UAC. Отказывайтесь от установки пакетов из неизвестных источников.

## Разработка и сборка

Требуются Windows 10/11 x64 и .NET 8 SDK. Чтобы подготовить значок, выполнить сборку и создать установщик:

\`\`\`powershell
.\scripts\Generate-Icon.ps1
dotnet restore .\DjShrek-Draiver.sln
dotnet build .\DjShrek.Draiver.sln -c Release
dotnet publish .\src\DjShrek.Draiver.App\DjShrek.Draiver.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\artifacts\win-x64
choco install innosetup --yes
iscc .\installer\DjShrek-Draiver.iss
\`\`\`

Windows CI автоматически выполняет сборку Release, публикацию EXE, компиляцию установщика и проверку наличия обоих файлов.
